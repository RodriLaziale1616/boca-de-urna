# Privacidad

El sistema está diseñado para una encuesta anónima. La tabla `Vote` no incluye nombre, cédula, teléfono, email ni IP del votante. El sistema registra únicamente la opción seleccionada, el operador, el local, la elección, un identificador técnico de idempotencia y la fecha/hora.

No agregar campos identificatorios de votantes sin una revisión separada de necesidad, base legal, retención y controles de acceso.
