# Runbook breve

## Antes de abrir la encuesta

1. Confirmar candidatos, listas, colores y locales.
2. Confirmar operadores asignados.
3. Hacer un registro de prueba con cada tipo de dispositivo.
4. Verificar que el dashboard actualiza en tiempo real.
5. Activar la elección solo cuando corresponda.

## Durante la encuesta

- Vigilar operadores sin actividad.
- No modificar candidatos una vez activada.
- Mantener conectividad estable.
- Si un operador pierde internet, la pantalla bloquea nuevos registros hasta reconectar.

## Cierre

1. Cambiar la elección a `CLOSED`.
2. Confirmar que ningún operador puede registrar nuevos votos.
3. Verificar el total final y cortes por hora.
4. Respaldar PostgreSQL.
