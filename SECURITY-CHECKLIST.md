# Checklist de salida a campo

- [ ] Repositorio privado.
- [ ] `NODE_ENV=production`.
- [ ] Contraseña de administrador larga y única.
- [ ] PostgreSQL con backup habilitado.
- [ ] Una sola réplica en Railway para el MVP.
- [ ] Operador recibe 403 en `/api/admin/*`.
- [ ] Administrador puede cerrar la elección y bloquear nuevos votos.
- [ ] Dispositivo offline no permite registrar.
- [ ] Doble toque no duplica votos.
- [ ] Resultados no aparecen en pantalla del operador.
- [ ] Prueba responsive en Android, iPhone, tablet y notebook.
- [ ] Prueba de carga con volumen esperado antes de la elección.
